TAU α / TECHNICAL NOTES / V0.5.0

Small hardware.
Serious care.

Tau is an audio-first system for the Analogue Pocket FPGA. Playback is the protected invariant; the interface, artwork and meters are designed to work around it.

● Hardware-confirmed◆ Simulation-verified○ Design / roadmap
SD card / APF→VexRiscv→Helix + FLAC→PCM FIFO→EQ / I²SVexRiscv → Helios UI framework → Talos → SDRAM framebuffer → 400 × 360 / 60 Hz

01 / PLATFORM

The machine Tau runs on.

The core targets the Pocket’s Cyclone V FPGA. A soft CPU coordinates decode and UI; dedicated hardware protects recurring audio and visual work.

CPUVexRiscv

RV32IM softcore, 60 MHz, no FPU. It runs the cooperative decoder and UI loop.

HARDWARE-CONFIRMED
VIDEO400 × 360

RGB565 framebuffer in SDRAM, scanned at 60 Hz. Talos writes it without per-pixel CPU drawing.

HARDWARE-CONFIRMED
MEMORY256 KB + 64 MB

On-chip RAM, 32 MB SDRAM and 32 MiB PSRAM windows for frames, art, libraries and cold code.

HARDWARE-CONFIRMED
DEVICECyclone V

Target: 5CEBA4F23C8. System, SDRAM and video each run in their own clock domain.

HARDWARE-CONFIRMED

TALOS2D DRAW ENGINE

A draw engine, not a GPU.

Talos is a serial command-queue blitter that shares SDRAM fairly with scanout. It trades modern graphics generality for predictable, bounded work.

Firmware01MMIO02256-word FIFO03Talos04SDRAM

Built primitives

Runs, rectangles, glyphs, copies, palette blits, scaled blits, rounded rectangles and meter columns keep common UI operations compact.

● SHIPPED / HARDWARE-CONFIRMED

Why it matters

Scanline fill wins arbitration. Talos yields in burst-sized work, so visual activity does not become audio jitter.

● LOAD-TESTED WITH AUDIO

Blend path

Alpha blending has a timing-closed pipeline but is not in the shipped bitstream or firmware path yet.

◆ FIT / NOT SHIPPED
HELIOSUI FRAMEWORK

Draw at the right moment.

Helios is Tau’s lightweight graphical UI library over Talos. Named screen regions mark themselves dirty; a single flush point turns those changes into Talos commands when the video beam makes it safe.

H0

Frame timing

Vblank and a frame counter cross safely into the system clock domain.

● HARDWARE-CONFIRMED
H1

Beam-aware regions

Meter rows can wait for safe scan positions before drawing, avoiding visible tearing.

● HARDWARE-CONFIRMED
H2

Double buffer

Pointer-swapped SDRAM framebuffers for full redraws. Built and verified in simulation; not yet fit or run on Pocket.
